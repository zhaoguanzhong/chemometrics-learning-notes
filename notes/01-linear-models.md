# 线性模型：y = Xβ + ε

## 模型

- `y`：待预测的量（例如浓度），长度为 n 的向量。
- `X`：输入矩阵（例如 n 个样本 × p 个波长），每一行是一个样本的光谱。
- `β`：回归系数，`ε`：噪声。

最小二乘（OLS）估计：

```
β̂ = (XᵀX)⁻¹ Xᵀy
```

## 优点

- 可解释：每个系数对应一个输入变量的权重。
- 计算简单，结果稳定（在条件满足时）。

## 在光谱数据上为什么容易出问题

1. **共线性**：相邻波长高度相关，`XᵀX` 接近奇异，系数估计方差爆炸。
2. **高维**：波长数 p 常常大于样本数 n，OLS 无唯一解。
3. **非线性**：真实关系未必是线性的，线性模型只能近似。

这三点正是 PLS 被发明的原因：先把高维共线性的 X 压缩成少数潜变量，再回归。
