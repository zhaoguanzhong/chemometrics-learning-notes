# 模型转移与校正维护：模型换一台仪器还能用吗

在主仪器（master）上建好的定量模型，拿到另一台仪器
（slave）或同一台仪器换了部件、换了环境之后直接用，
预测往往会变差。这不是模型本身错了，而是光谱变了：
波长漂移、分辨率差异、增益和基线不同，都会让
“同一批样品的光谱”在新仪器上长得不一样。
模型转移（calibration transfer）就是在不重建完整
校正集的前提下，让旧模型在新仪器上重新可用；
校正维护（calibration maintenance）则是模型上线后
持续监控、定期修正的整套做法。

## 先判断：到底是哪种变化

动手之前先区分变化的来源，方法选错会白忙：

- **仪器间差异**：主、从仪器光源、检测器、光栅不同，
  光谱整体有系统性偏差，转移时需要两台仪器都测过的
  转移样品（transfer samples）。
- **同一仪器随时间漂移**：灯老化、温度变化、样品池
  更换。漂移较慢时可先做斜率/截距修正；漂移大或
  波长变了，才需要光谱层面的转移。
- **样品或工艺变化**：新原料、新批次、浓度范围外推。
  这不属于仪器转移，而是模型适用范围变了，
  往往需要补测样品、扩充校正集或重建模型。
  转移方法修不好“样品变了”的问题，这一点要先说清。

一个实用的诊断是：拿同一批样品在两台仪器上各测一次，
直接比较预测误差——主仪器上准、从仪器上偏，
且误差有系统性方向（整体偏高或偏低、随浓度变化），
就指向仪器差异；如果误差没有规律、随机散开，
更可能是噪声或样品本身的问题。

## 三种常用做法，由简到繁

### 1. 斜率 / 截距修正（slope/bias correction）

最简单：用少量从仪器样品（需有参考值）对旧模型的
预测值做一次线性修正，`y_corrected = a * y_pred + b`。
它只修正预测结果，不动光谱，适合光谱形状基本没变、
只是整体偏移或比例变了的情况。
优点是样品少、实现简单；缺点是光谱本身的波长漂移
和形状变化它修不了。

### 2. 直接标准化（Direct Standardization, DS）

把从仪器的光谱“翻译”成主仪器的光谱，再用旧模型预测。
做法是：用一批转移样品（两台仪器都测过）拟合一个
从从仪器光谱到主仪器光谱的变换矩阵 F，
`X_master ≈ X_slave · F`，新样品先经 F 变换再预测。
经典 DS 用全部波长拟合 F，转移样品数少于波长数时
容易过拟合，需要正则化或降维。

### 3. 分段直接标准化（Piecewise Direct Standardization, PDS）

DS 的改进：每个主仪器波长只用从仪器上附近一小段
窗口的波长来拟合，而不是全部波长。窗口宽度是一个
超参数，太窄修不好漂移，太宽又回到 DS 的过拟合。
PDS 在波长漂移明显的场景里通常比 DS 稳健，
是实际应用中最常用的转移方法之一。

除了这三种，还有基于模型参数的转移（如把 PLS 的
回归系数迁移、Shenk–Westerhaus 的方法）和近年
用迁移学习的做法，思路相同：旧知识尽量复用，
只用少量新数据补齐差异。

## 转移样品怎么选

转移样品的质量决定转移成败，几点经验：

- **覆盖范围**：转移样品的浓度与光谱变化范围要
  覆盖未来样品，否则转移矩阵在范围外不可靠。
- **有代表性**：优先选光谱差异大的样品（如用
  Kennard-Stone 算法在主仪器光谱里挑分布均匀的样品），
  而不是随手拿最前面的几瓶。
- **数量**：斜率/截距修正十几个样品可能够用；
  DS / PDS 需要更多，一般几十个起步，且要留出
  独立的验证样品——不能拿拟合转移矩阵的样品
  来证明转移成功，否则结果会被高估。
- **稳定性**：转移样品本身在两次测量之间不能变质，
  否则“仪器差异”里会混进样品变化。

## 校正维护：模型不是建完就完事

模型上线后要像仪器一样定期“体检”：

1. **常规质控样**：定期测已知浓度的质控样，
   把预测误差画成控制图，误差持续漂移或超限就报警。
2. **定期复核**：每隔一段时间（或换部件、换季节后）
   用一批新样品复核 RMSEP，变差到阈值就触发修正。
3. **修正阶梯**：先试斜率/截距修正；不够再做 DS / PDS；
   再不够就把新样品并入校正集扩充（model updating）；
   最后才是重建模型。每一步都要在独立验证集上确认
   真变好了，再替换线上模型。
4. **留记录**：每次修正的时间、用的样品、修正前后的
   RMSEP 都要记下来——这正是本仓库 CHANGELOG
   的做法，出了问题才能回溯是哪一步动了模型。

## 常见坑

- **只在转移样品上验证**：转移矩阵就是在这些样品上
  拟合的，验证必须用没参与拟合的独立样品。
- **转移样品太少又用全波长 DS**：参数比样品多，
  拟合得再好也是过拟合，换一批样品就失效。
- **把样品变化当仪器问题修**：新批次原料变了，
  光谱转移修不回来，硬转只会掩盖真正的变化。
- **一次转移管终身**：仪器还会继续漂移，转移
  模型本身也需要定期复核和更新。

在合成数据上模拟主、从仪器（波长漂移 + 增益 + 基线），
对比“从仪器光谱直接预测”“斜率/截距修正”
和“直接标准化转移”三种做法的测试集误差。
实测中斜率/截距修正已明显改善预测，但残差仍高于

这正是“只修正预测值”与“修正光谱本身”的区别。
