# 评价指标：RMSEP、R² 与偏差

## RMSEP（预测均方根误差）

```
RMSEP = sqrt(mean((y_true - y_pred)^2))
```

单位与 y 相同，是光谱定量最常用的指标：越小越好。
注意区分：RMSEC（校正集）、RMSECV（交叉验证）、RMSEP（独立测试集），
三者数字不能直接混着比。

## R²（决定系数）

表示模型解释的 y 方差比例，越接近 1 越好。
但 R² 只看相对拟合：y 本身波动大时，R² 容易虚高；
报结果时应同时给出 RMSEP。

## Bias（偏差）

```
bias = mean(y_pred - y_true)
```

系统性偏高或偏低说明模型有系统误差，可能是预处理或样本代表性问题。

## 报告规范

- 同时报告 RMSEP 与 R²，最好加上样本数 n。
- 明确说明是交叉验证结果还是独立测试集结果。
- 不要只报训练集指标。
