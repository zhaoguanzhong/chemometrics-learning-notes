## 多元曲线分辨（MCR）：不分离样品，直接拆出纯组分

混合物光谱常常是几个组分光谱叠加的结果：峰重叠在一起，
色谱没分开，或者样品根本没法逐个分离提纯。多元曲线分辨
（Multivariate Curve Resolution, MCR）要解决的就是这个问题：
只用混合物的光谱数据，把每个纯组分的“光谱长什么样”
和“每个样品里各有多少”同时拆出来。

## 基本模型：双线性分解

设混合光谱矩阵为 X（n 个样品 × p 个波长），MCR 的模型是：

`X = C · Sᵀ + E`

- C（n × k）：浓度（或分布）矩阵，第 i 行是第 i 个样品中
  k 个组分的相对含量；
- S（p × k）：纯光谱矩阵，每一列是一个组分的纯光谱；
- E：残差，理想情况下只是测量噪声；
- k：组分数，需要事先确定或从数据中判断。

和 PLS 不同，MCR 建模时不需要已知浓度 y；和 PCA 不同，
MCR 拆出的不是数学上正交的抽象主成分，而是希望对应
真实化学组分的浓度和光谱。正因为 C 和 S 都未知，
这是一个双线性问题，比普通回归难一截。

## 最大的难点：旋转模糊

模型本身有一个根本的不确定性：对任意可逆矩阵 T，都有

`X = C · Sᵀ = (C · T) · (T⁻¹ · Sᵀ)`

也就是说，数学上存在无数组等价的 C 和 S，都能同样好地
拟合 X。这叫旋转模糊（rotational ambiguity）。
只看“拟合得好不好”无法区分它们，必须靠化学先验知识
（约束）把解收窄到合理范围。这是 MCR 和 PCA、NMF
最本质的区别之一：约束不是可选项，而是方法的一部分。

## 常用约束：把解收窄到化学上合理

- **非负性**：浓度和光谱强度都不应为负，这是最常用、
  也最稳妥的约束；本仓库示例就只用了这一条。
- **单峰性**：色谱或反应过程曲线里，一个组分的分布
  曲线通常只有一个峰，不应出现多个峰。
- **闭合性**：混合物各组分含量之和恒定（如质量分数
  之和为 1）时，C 的每一行之和应为常数。
- **选择性**：某些波长只属于一个组分，或某些样品只含
  一个组分——这些“纯变量”“纯样品”能大幅收窄解的范围。
- **已知信息固定**：某组分的纯光谱或某样品的浓度已知时，
  直接把对应的 C 或 S 列固定住，不参与迭代。
- **归一化**：C 整体放大、S 整体缩小，乘积不变，
  这是尺度模糊。常见做法是把每列纯光谱归一化到最大值为 1
  （或范数为 1），让 C 吸收尺度；这样得到的浓度是相对量，
  要得到绝对浓度还需用标准样品标定。

约束越多，解越唯一，但约束本身也可能错：例如真实光谱
有负向的差分信号时硬加非负性，反而会扭曲结果。
约束要来自对体系的了解，而不是为了让图好看。

## MCR-ALS：最常用的算法流程

MCR-ALS（交替最小二乘）是应用最广的 MCR 算法，步骤如下：

1. **定组分数 k**：对 X 做 SVD，看奇异值的断点；
   明显大于噪声水平的奇异值个数就是 k 的初步估计。
   组分数定少了会把两个组分并成一个，定多了会把噪声
   拆成“假组分”，两者都要避免。
2. **给初始估计**：需要一个初始的 C 或 S。常用方法有
   最纯变量法（SIMPLISMA：找只属于一个组分的波长）、
   已知的纯光谱、或针对过程数据的渐进因子分析（EFA）。
   本仓库示例用最纯变量法：纯度用“标准差 /（均值 + 偏移）”
   衡量，挑出的波长彼此间隔足够远，避免重复选同一组分。
3. **交替求解**：固定 S，用非负最小二乘（NNLS）解 C；
   再固定 C，用 NNLS 解 S；每一步都施加约束。
4. **迭代到收敛**：重复第 3 步，直到残差的相对变化
   小于阈值（如 0.1%）或达到最大迭代次数。
5. **检查结果**：残差水平是否接近噪声水平、纯光谱是否
   物理合理（峰位、峰形、无不合理的负值或振荡）、
   浓度分布是否符合过程常识。

## 怎么评价结果：残差低不等于拆对了

常用指标是失拟度（lack of fit, LOF）：

`LOF = 100% × sqrt(ΣE² / ΣX²)`

LOF 低说明模型拟合了数据，但由于旋转模糊的存在，
LOF 低并不能证明拆出的就是真实组分。可靠的验证
必须借助模型之外的信息：与已知纯光谱的相关系数、
加标样品的回收情况、质量平衡是否闭合、浓度分布
是否符合反应或分离过程的预期。没有这些佐证时，
结论只能写成“在所加约束下得到的一组合理解”，
而不是“这就是真实的纯组分”。

## 常见坑

- **组分数错了**：SVD 断点不明显时，宁可多做几组
  不同 k 的对比，看纯光谱和浓度分布哪一组更合理，
  不要只看 LOF——k 越大 LOF 一定越小。
- **初始估计不好**：ALS 是局部优化，初始估计离谱时
  可能收敛到不合理的局部解；换一种初始估计方法
  对比结果，是必要的稳健性检查。
- **忘了预处理**：基线漂移、散射差异会先被拆成
  “组分”，建模前应先做基线校正或适当的预处理。
- **把相对浓度当绝对浓度**：尺度模糊意味着 MCR
  直接给出的是相对分布；不经标定就报绝对浓度是错的。
- **和 PCA、NMF 混淆**：PCA 的主成分可以为负、
  也不对应真实组分；NMF 同样是非负分解，但通常
  不加单峰、闭合、选择性等化学约束，解的化学
  可解释性不如加了约束的 MCR。

## 和其他方法的关系

- 需要已知浓度 y、目标是预测时，用 PLS / SVR / 随机森林；
- 只想降维、看样品分布时，用 PCA；
- 想在没有 y、也无法分离样品的情况下拆出纯组分
  和相对含量时，才用 MCR。

本仓库的配套示例见 `examples/mcr_example.py`：
在合成的三组分混合光谱上，用最纯变量法初始化、
交替非负最小二乘迭代，拆出的三条纯光谱与真实纯光谱
的相关系数均为 1.000，LOF 为 4.01%、R² 为 0.997。
注意这是合成数据上的演示：真实数据里峰重叠更严重、
噪声和基线更复杂时，恢复精度会低于这个理想结果，
且必须用已知纯光谱或加标样品做外部验证。
